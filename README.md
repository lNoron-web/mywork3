# Практична робота №3 — Базовий синтаксис CSS та GitHub Pages

## Структура

```text
work 3/
├── css/
│   └── style.css
├── fonts/
│   └── .gitkeep
├── image/
│   ├── favicon.svg
│   ├── logo.svg
│   ├── news1.svg
│   ├── news2.svg
│   ├── news3.svg
│   └── news4.svg
├── index.html
├── news.html
├── education.html
└── contacts.html
```

Не копіюйте та не замінюйте папку `.git` з іншого проєкту. У цьому архіві її навмисно немає.

## GitHub Pages

У репозиторії відкрийте Settings → Pages. Встановіть Source: `Deploy from a branch`, Branch: `main`, Folder: `/(root)`, натисніть Save.
