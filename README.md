# Практична робота №3 — Базовий синтаксис CSS та GitHub Pages

Це самодостатній навчальний багатосторінковий сайт. Усі файли, зображення та стилі містяться в архіві локально. Єдине зовнішнє підключення — Google Fonts (Roboto); якщо інтернет недоступний, браузер використає Arial.

## Структура

```text
work 3/
├── css/
│   └── style.css
├── fonts/
│   └── .gitkeep
├── image/
│   ├── favicon.svg
│   ├── logo.svg
│   ├── news1.svg
│   ├── news2.svg
│   ├── news3.svg
│   └── news4.svg
├── index.html
├── news.html
├── education.html
└── contacts.html
```

## Перед здачею роботи

1. Перевірте та за потреби замініть демонстраційну таблицю розкладу на фактичний розклад поточного семестру.
2. Новини та зображення у `image/` є демонстраційними навчальними матеріалами, а не підтвердженими новинами університету.
3. Форма контактів демонстраційна: GitHub Pages не обробляє її та не надсилає повідомлення.
4. Якщо викладач вимагає саме фотографії, замініть SVG-ілюстрації `news1.svg`–`news4.svg` на фотографії та відповідно змініть `src` у `news.html`.

## Локальна перевірка

Відкрийте `index.html` у браузері або запустіть папку через Visual Studio Code + Live Server.

## Завантаження в уже клонований Git-репозиторій

Розпакуйте вміст архіву безпосередньо в папку `Documents/work 3`, погодившись на об'єднання папок та заміну файлів, якщо Windows запитає.

У Git Bash:

```bash
cd ~/Documents/"work 3"
git status
git add .
git commit -m "Додано повний сайт для практичної роботи 3"
git push origin main
```

Не копіюйте та не замінюйте папку `.git` з іншого проєкту. У цьому архіві її навмисно немає.

## GitHub Pages

У репозиторії відкрийте Settings → Pages. Встановіть Source: `Deploy from a branch`, Branch: `main`, Folder: `/(root)`, натисніть Save.
